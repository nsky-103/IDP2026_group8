\section{Discussion}

Coarse-first loading improves responsiveness on multi-gigabyte files, but detection and
full-accuracy views still require the \SI{1}{\kilo\hertz} summary. LTTB improves visual peak
fidelity under a fixed point budget; the downsampled series is for display only, while
detection uses the summary or exact windows. The event list is limited to the strongest
accepted pieces so the UI stays usable on long recordings with many detections; rejected
(\texttt{water}) pieces are omitted from that list unless shown elsewhere as rejected
markers.
