\section{Discussion}

The Streamlit tool is meant for interactive browsing, not for replacing the offline
pipeline. Coarse-first loading trades a short preview phase for responsiveness on
multi-gigabyte files; detection still waits for the \SI{1}{\kilo\hertz} summary.
LTTB improves visual fidelity of peaks under a fixed point budget, but the downsampled
series is for display only---quantitative detection should use the \SI{1}{\kilo\hertz}
summary or exact sample windows. Alternative downsamplers (for example stride) remain
available in the UI for comparison.
